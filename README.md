# Bright Vision Digital Design

Production-style single-page agency website for Bright Vision Digital Design.

## Deploy on GitHub Pages

1. Create a GitHub repository, for example `bright-vision-website`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

The website uses Tailwind CSS, Lucide Icons and Unsplash images through CDNs, so an internet connection is needed for those external resources.
